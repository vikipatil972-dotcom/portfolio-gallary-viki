## 📌 About the Project

This repository contains my personal portfolio gallery, where I display my work in a visually organized layout. It is built to be fast, lightweight, and easy to customize.

## ✨ Features

- 📱 Fully responsive layout (mobile, tablet, desktop)
- 🖼️ Clean image/project gallery grid
- 🎨 Smooth hover effects and transitions
- ⚡ Fast loading, no heavy frameworks
- 🧩 Simple structure, easy to edit and extend

## 🚀 Getting Started

### Run locally

```bash
# 1. Clone the repository
git clone https://github.com/vikipatil972-dotcom/portfolio-gallary-viki.git

# 2. Go to the project folder
cd portfolio-gallary-viki

# 3. Open index.html in your browser
# (or use the Live Server extension in VS Code)
```

### Deploy on GitHub Pages

1. Go to **Settings → Pages**
2. Under **Source**, select the `main` branch and `/ (root)`
3. Click **Save** and your site will be live in a minute

## 🔧 Customization

- Replace the images in the `images/` folder with your own work
- Edit text and links in `index.html`
- Change colors and fonts in `css/style.css`
